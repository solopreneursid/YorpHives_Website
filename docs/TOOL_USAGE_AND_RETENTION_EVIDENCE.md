# Tool-use evidence and privacy-preserving return visits — November 2026

## Facts, not projections

On 2026-11-18 the live read-only `GET /api/insights/growth` reported **29 page views and zero accepted browser-reported tool completions** across the available 30-day window. It returned an empty ranked list and **no independently verified revenue feed**. This is insufficient to name a most valuable tool or category. These numbers are an observed snapshot, not a forecast or claim about unique people.

## Current measurement (already deployed)

- The first-party browser script sends event **view** for high-level site sections and **complete** for approved tool routes. Only successful processing state triggers completion; no file contents, filenames, output text, calculator inputs, search terms or saved-tool URLs are transmitted by the retention feature.
- Browser-tab random session IDs are digested before storage. Existing analytics honors Do Not Track, Global Privacy Control and an opt-out. A visitor can use every tool without sending events.
- Counts are deduplicated at bounded intervals and retained for 35 days. A completed action is **not** a payment, a unique person, a successful download or confirmed satisfaction.
- `GET /api/insights/growth` already offers 30-day daily counts, 7-day comparisons, top tool completions and founder-reviewed investigation candidates. The updated report **adds category aggregates** from the same approved-tool catalog and the **same existing daily completion table**; no D1 schema migration or extra collector is required.
- `categories` reports `availableTools`, `toolsWithSignals`, `completedActions30d`, `completedActions7d` and `previous7d`; only published tool routes contribute. There is no paid or unpublished product data, fabricated conversion metric or automatic winner selection.

## Interpreting results

| Signal | Safe interpretation | Unsupported claim |
| --- | --- | --- |
| 30-day browser-reported completions | Relative tool processing activity from participating sessions | Unique customers or independent human demand |
| More completions this week than prior week | Possible momentum worth investigating | Viral growth or market leadership |
| Few/no completions | Incomplete data or low recorded usage | The product has no users |
| Browser saved-tool shortcuts | A useful convenience to revisit a tool | Measured repeat visitors or retention rate |

**Decision rule:** do not declare a "popular" category until sufficient activity is recorded and reliability is checked. Even 5+ events from a category could be generated by one visitor. Compare trends and product usefulness qualitatively; founder approval remains required for new products, ads, sponsored posts or checkout.

## Visitor experience

- The directory now displays a **local-only saved-tools shortcut shelf** when the visitor has saved one or more published tools.
- It uses the existing `yorphives-studio-saved-v1` browser key; no cookies, account, new database, uploads, outbound events, or server-side recommendations.
- It displays at most six validated, catalog-backed URLs. Links are created as text DOM nodes (never from untrusted HTML). Unsupported or unpublished routes are omitted.
- The original 143 static category links stay crawlable and usable with JavaScript disabled. Visitors with blocked storage still have the standard tool directory.
- Saved-tool data remains on that browser/device; no cross-device sync or historical usage analysis is implied.
