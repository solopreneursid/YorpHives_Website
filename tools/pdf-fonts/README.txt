The fixed local font pack is downloaded when a supported PDF tool is used;
text and documents are never sent in that request. Needed fonts are loaded
from the pack on the visitor's device. The pack may be rebuilt with
`python3 scripts/build-pdf-font-pack.py /usr/share/fonts/truetype/noto`
using Python fontTools and the same reviewed Noto font files.
