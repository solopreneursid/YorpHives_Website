Format, minify, and validate JSON while preserving the original numbers.

How to format JSON

  1. Paste valid JSON into the input box.
  2. Choose an indentation size and select Format JSON, or use Minify.
  3. Copy or download the result.

Private by design

Formatting and validation happen in your browser. Your JSON is not uploaded. Original number and string representations are retained, including large integers.

Example uses and limitations

Use Format JSON to inspect nested objects with consistent indentation, or Minify to remove unnecessary whitespace for transfer or storage. Invalid JSON cannot be formatted as valid JSON: check the reported error and fix the input. The tool formats text; it does not check whether a JSON document matches a particular application schema.
