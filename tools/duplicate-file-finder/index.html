    How to use this tool

    1. Enter your information and choose any options.
    2. Run the tool to see the result.
    3. Download the result when it is ready.

    Good to know

    Choose 2–20 files, maximum 12 MB each and 30 MB total. Only selected files are checked. Matching sizes are hashed and compared byte-for-byte; the tool does not delete files. Processing happens on your device.
