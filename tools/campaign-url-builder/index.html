How to build a campaign link

  1. Enter the page you want visitors to reach.
  2. Add the campaign details you want to track.
  3. Build and copy the link into your campaign.

What happens to existing parameters?

Other query parameters and fragments are kept. Fields you fill in replace any matching UTM values already in the URL. The link is created locally; it is not sent to YorpHives.
